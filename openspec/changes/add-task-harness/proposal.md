# Outcome-scoped coding harness

Developers arrive with work in different states. Let a host understand the request once and use a deterministic local record to select the next action. Reuse existing Git snapshots, private ledger, check runner, logs and native usage observations. Keep the managed role workflow and compact opt-in available. Expose plan, implementation, review, verification and delivery as distinct stopping points. Review-only may finish with findings. A verified delivery needs current executable evidence. Gate detachment should preserve evidence by default.

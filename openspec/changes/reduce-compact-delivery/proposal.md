# Reduce repeated compact delivery

The paired Sol/high experiment completed both candidates with passing frozen
checks but captured 9.8% more total tokens with compact. Repeated coordinator
instructions, support-guide reads, quiet-check envelopes and one rejected
optional return provide specific opportunities, without proving their causal
token costs.

Shorten generated native handoffs, make saved worker policy sufficient without
repeated coordinator guides, prefer ordinary quiet checks and avoid state reads
before history exists. Clarify minimal optional returns and replay observed
claim failures offline. Preserve full user assignments, original role bodies,
selected skills, permissions, review and gate requirements. Compact stays
opt-in; no paid run, model routing change, commit or publication is included.

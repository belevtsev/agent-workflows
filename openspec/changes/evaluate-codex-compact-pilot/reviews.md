# Reviews

Independent agents own source curation, grading/isolation review and
the execution/accounting harness. The original foundation used Sol/max; the
budget replacement and its runtime use Sol/high. Eligibility audits corrected
unsupported prompt expectations before measured execution. Final implementation,
protocol and result review evidence follows.

- Runtime/grading review found that candidate-controlled Git filters and ignored
  baseline paths needed host-side protection. The capture path reconstructs a
  trusted Git database without executing solver configuration; local regressions
  cover command nonexecution and preservation of ignored frozen files.
- Independent protocol audit binds all 24 results, prompts, source attestations
  and traces. All 108 actual sessions use Sol/high. Unknown encrypted message
  equality remains unknown; observable mechanics and full protocol certification
  are reported separately. Substring mentions do not count as executed commands.
- All 24 blind reviewer attempts finished before the arm mapping was opened.
  Twenty-one produced valid reviews and three timed out. Two reported major
  findings in the charset task. A separate agent, still blind to the mapping,
  confirmed the supplied HTTP inputs on baseline and both opaque candidates:
  an extended-parameter regression affects both, and a stray-quote regression
  additionally affects normal mode. Frozen scores remain unchanged.
- Posthoc blind-bundle preparation exposed a tar-padding pipe deadlock. The
  separate helper now drains bounded padding before waiting, with padding and
  oversize regressions. Frozen solver binaries and inputs were preserved; all
  actual frozen graders already exited zero, so no result was rescored.
- Required-check integration exposed a nondeterministic fixture assertion about
  order across stdout/stderr. The failing fixture now writes its routine output
  and final diagnostic to one stream. Its assertions pass 30 race repetitions.
  No production log merge ordering was changed.
- A separate Sol/high agent reviewed the final report against raw solver,
  protocol, blind-review, mapping and confirmation artifacts. It found no
  actionable discrepancy in totals, timing, interpretation or reviewed harness
  integration. In particular, zero complete token pairs and both arms' confirmed
  additional defects remain explicit. This review made no model CLI calls or edits.

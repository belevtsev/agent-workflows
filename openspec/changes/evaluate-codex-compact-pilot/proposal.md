# Evaluate compact context on real Codex tasks

The collector's deterministic output-size tests do not establish task-wide
token savings or preserved coding quality. Implement and run a separately
labeled, Codex-only comparison of compact mode off/on with identical workflow
policy, model and reasoning effort.

Current scope: twelve pinned historical defects, one repetition per condition,
24 measured runs, Sol at high for every role, an eight-minute run limit, independent acceptance/regression
grading, causal session accounting and a detailed report. Preserve failures,
unknown usage, calibration costs and study limits. Do not change production
workflow policy to improve the benchmark.

The user replaced the initial 72-run Sol/max design to reduce time and token
consumption. Its 13 started attempts are retained as a separate partial phase,
including six operator cancellations; unstarted identities are not failures.
The harness supports both frozen profiles. No outcomes or usage are pooled
across changed profiles.

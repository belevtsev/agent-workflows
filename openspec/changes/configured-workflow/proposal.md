# Supervise configured role workflows

Keep one host and model assignment per role and one task record across Codex
and Claude Code. Separate check execution and worker evidence from the live
developer checkout.

- Pin the reviewed runner policy, exact candidate, intake assertion and role settings.
- Delegate each automated step to an administrator-registered disposable runner.
- Require authentic, current results for verification, review and recovery.
- Keep the CLI and matching plugin installation independent of runner setup.

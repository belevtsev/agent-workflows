Capture the selected project's baseline and an explicit JSON requirement/check plan in a new private task record.
The record binds the advisers configured now: each provider the model policy enables whose credential is set (TYPESAFE_API_KEY, SUBQ_API_KEY or OPENAI_API_KEY, from the environment or saved keys) and that you opted in to, mapped to its pinned model, possibly none.
You opt in to a provider by listing it under advisers.enabled in preferences.json of the configuration directory or by saving its key with 'cw keys set'; --policy opts in to every provider that policy enables.
A key in the environment alone binds no adviser.
An adviser disabled in your saved preferences (advisers.disabled) is never bound, even with --policy; an unreadable or invalid preferences file fails before any task is created.
Saved keys that cannot be read opt in to nothing: the task starts without them and a warning on stderr names the problem.
The binding never changes for the task's lifetime; 'cw task context' carries it to 'cw consult'.
An unreadable or invalid policy fails before any task is created.
The record also fixes the pack set: the selected packs ('cw pack list') whose detect file is at the top of the selected path now; an unreadable pack selection, or a selected pack not built into cw, fails before any task is created.
